# Cursor Budget

A **single HTML file** to track your estimated Cursor spend. No install, no server, no npm, no Python — open the file in any browser.

## Use it

1. Open `tools/cursor-budget/index.html` in Chrome, Safari, or Firefox (double-click or drag into the browser).
2. Set your monthly budget.
3. Before a Cloud Agent run, use the checklist.
4. Tap a quick-add button or log a custom amount after each session.

Everything is stored in **localStorage on your machine**. Nothing is sent over the network.

## Why it costs nothing to run

- One static file (~6 KB)
- No background process
- No dependencies
- No Cursor API calls

Edit the preset dollar amounts in the HTML if your plan’s usage costs differ — they are labels for **your** estimates, not live billing data. For official usage, check **Cursor → Settings → Billing**.
